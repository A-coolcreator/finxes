## 5. Category Collision & Disambiguation Rules *(new — enrichment)*

Several brand strings recur across categories. First-match keyword scanning will misclassify these. Apply in this order:

1. **Longest-phrase-wins.** Always test multi-word phrases before their single-word substrings. `AMAZON PAY BALANCE` → CAT-24 (Wallet), checked before `AMAZON PAY` → CAT-01 (UPI App), checked before bare `AMAZON` → CAT-06 (Ecommerce).
2. **Suffix/context disambiguation table** for the flagged brands:

| Brand root | Variant | Correct category |
|---|---|---|
| AMAZON | `AMAZON` (bare, order-ID pattern) | CAT-06 Ecommerce |
| | `AMAZON PAY` / `AMAZONPAY` (VPA suffix `@apl`) | CAT-01 UPI App |
| | `AMAZON PAY BALANCE` | CAT-24 Wallet |
| | `AMAZON PRIME` | CAT-34 Subscription |
| | `AMAZON SETTLEMENT` | CAT-33 Ecommerce Settlement |
| PAYTM | `PAYTM UPI` | CAT-01 UPI App |
| | `PAYTM PG` | CAT-02 Payment Gateway |
| | `PAYTM WALLET` | CAT-24 Wallet |
| | `PAYTM MONEY` | CAT-16 Broker |
| | `PAYTM FASTAG` | CAT-27 Fastag |
| | `PAYTM LOAD` | CAT-37 Wallet Load |
| | `PAYTM SETTLEMENT` | CAT-31 PG Settlement |
| TATA | `TATA CAPITAL` | CAT-10 NBFC |
| | `TATA AIA` | CAT-18 Insurance |
| | `TATA 1MG` | CAT-50 Healthcare |
| | `TATAPLAY` | CAT-26 Recharge (DTH) |
| CASHFREE | always | CAT-02 Payment Gateway — never CAT-22 Cash Deposit even though it contains "CASH" |
| SWIGGY / ZOMATO / UBER / OLA / RAPIDO | bare brand | CAT-07/08 (Food/Mobility spend) |
| | brand + `PAYOUT` | CAT-39 Gig Economy (this is the driver/partner receiving money, not the customer spending) |
| MAX | `MAX LIFE` | CAT-18 Insurance |
| | `MAX HEALTHCARE` | CAT-50 Healthcare |
| VISA / MASTERCARD / RUPAY | bare, in POS/card-swipe narration | CAT-05 Merchant POS |
| | + `SETTLEMENT` | CAT-36 Card Settlement |
| P2P | in crypto-exchange narration | CAT-20 Crypto P2P |
| | in NBFC/lending-platform narration (e.g. peer-to-peer lending apps) | **not** CAT-20 — route to CAT-09 Loan App or leave uncategorized; require exchange-name co-occurrence for CAT-20 |
| OPEN | `OPEN MONEY` (payment gateway narration) | CAT-02 Payment Gateway |
| | bare `OPEN` (neobank narration, business-banking context) | CAT-56 Neobank — require full-word isolation; `OPEN` alone is far too short to trust without account-type context (business current account) |
| RAZORPAYX | as a business-banking/neobank product narration | CAT-56 Neobank |
| | `RAZORPAYX` in a payment-collection/settlement narration | CAT-02 Payment Gateway — disambiguate by transaction direction and counterparty type (merchant collection vs. business account activity) |
| FI MONEY / JUPITER | as UPI-payment narration (VPA-style) | CAT-01 UPI App |
| | as savings/investment-feature narration (FD booking, mutual fund via app) | Route to CAT-43/CAT-17 instead, using the app name only as source-channel metadata, not the category itself |
| LAZYPAY | standard BNPL checkout narration | CAT-55 BNPL |
| | (already listed under CAT-09 Loan App in original taxonomy) | Treat CAT-55 as the more specific/correct category going forward; keep CAT-09 mapping as legacy alias only |
| AMAZON PAY LATER / OLA MONEY POSTPAID | | CAT-55 BNPL, not CAT-01/CAT-24 — "Pay Later"/"Postpaid" suffix always wins over the base brand's usual category |

3. **Direction check as tiebreaker**: e.g. `SWIGGY` debit (customer paying) = Food Delivery spend (Sec 8 rollup); `SWIGGY PAYOUT` credit (partner receiving) = Gig Economy income (CAT-39). Same brand, opposite category, disambiguated by Dr/Cr.

## 10. Exclusion / False-Positive Layer *(v1 layer, extended with new collisions found in this taxonomy)*

| Keyword rule | False positive example | Fix |
|---|---|---|
| `NACH` (CAT-13) | `RATNACHAUHAN`, `PANCHAL`, `KANCHAN` | `\bNACH\b` word boundary + require UMRN co-occurrence |
| `SI` (CAT-13, Standing Instruction) | Extremely short — collides broadly (initials, abbreviations in narration) | Never match bare `SI`; require full `STANDING INSTRUCTION` phrase or UMRN presence |
